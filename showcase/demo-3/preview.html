Apache fails to start with SSLCACertificateFile does not exist or is empty error in Plesk

Packet status: reviewer-only preview. Not public content. Not a Zendesk write. Not auto-publishable.

Applicable to

  • Plesk for Linux

Symptoms

  1. Apache fails to start with an AH00526 syntax error in generated Apache configuration.
  2. The error references SSLCACertificateFile under /usr/local/psa/var/certificates/, where the referenced file does not exist or is empty.
  3. All websites show the default Apache page.
  4. plesk repair web fails during web server reconfiguration.
  5. Apache configuration generation fails from the Plesk webserver template writer path.

Cause

Plesk bug PPPM-5892 causes broken Apache configuration files that reference a missing or empty SSL CA certificate file.

Resolution evidence

  1. Confirm Apache service failure with systemctl status httpd.
  2. Check Apache configuration syntax with /usr/local/psa/admin/bin/apache-config -t.
  3. Verify that the referenced certificate file is missing or empty under /usr/local/psa/var/certificates/.
  4. Apply existing public article guidance for PPPM-5892.
  5. Run plesk repair web after applying the fix.
  6. Start Apache and verify service status.
